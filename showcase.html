A dark-first, Preact component library crafted for modern web products. Every component is built with TypeScript, ships as an ES module, and is accessible by default.
Yes — every component is individually importable. If you only use Button and Badge, only those two modules end up in your bundle.
Preact is fully API-compatible with React. Add alias: { react: 'preact/compat' } to your bundler config and kova-ui works in any React project.

Why kova-ui

Built differently

Not just a component kit — an opinionated design system for products that take aesthetics seriously.

5.6kb gzipped
Zero runtime overhead. No polyfills, no bloat. Built on Preact's 3kb core.
Accessible by default
ARIA attributes, keyboard navigation, focus management — built in, not bolted on.
Tree-shakeable
Import exactly what you use. import {'{ Button }'} from 'kova-ui' and nothing else ships.
CSS custom properties
Every visual token is a CSS variable. Theme the entire library in 5 lines.
React compatible
One alias in your bundler. Use kova-ui in any React project with zero code changes.
TypeScript first
Full type definitions bundled. IntelliSense, prop completion, and type safety out of the box.
Quick start

One command

$ npm install kova-ui Copied!
Then import once at your app root:
import 'kova-ui/styles'
