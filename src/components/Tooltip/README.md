# Tooltip

Shows a label on hover or focus. Four placements.

## Import

```ts
import { Tooltip } from 'kova-ui'
```

## Basic

```tsx
<Tooltip content="Copy to clipboard" placement="top">
  <Button variant="ghost" iconOnly><CopyIcon /></Button>
</Tooltip>
```

## Placements

`top` (default) · `bottom` · `left` · `right`
